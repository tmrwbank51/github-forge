A GitHub-compatible git forge in dependency-free TypeScript: REST v3, GraphQL v4, MCP tools, and git smart-HTTP (protocol v2 upload-pack, v0 receive-pack) over one in-memory object store. No model calls, no wall clock, no unseeded randomness — every timestamp comes from the trial's fixed now and every id from a counter.

## Run it

```sh
node --experimental-strip-types main.ts
```
